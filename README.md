## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Installation

```bash
$ npm install
```

## Running the app

```bash
# development
$ docker compose up

```
## Backend NestJS GraphQL

```bash
# development
http://localhost:9300/graphql

```

## Frontend Nuxt 4 GraphQL

```bash
# development
http://localhost:5300

```

## Database Mysql

```bash
# development
http://localhost:8080

```
